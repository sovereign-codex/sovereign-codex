# How to Contribute

## Start Here
1. Read `README.md`
2. Read `00_FOUNDATION/`
3. Decide whether your contribution is:
   - constitutional
   - operational
   - cultural
   - experimental
4. Use `proposal_template.md` if the change affects structure or first principles

## Golden Rule
Contribute in a way that increases clarity, continuity, dignity, transparency, and long-term usefulness.
