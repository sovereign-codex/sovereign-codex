# AVOT Registry
## Sovereign Codex Intelligence Index

---

## Purpose

This registry defines all active Autonomous Voices of Thought (AVOTs) within the Sovereign Codex.

Each AVOT represents a distinct cognitive function within the system.

This registry ensures:
- clarity of roles
- non-overlapping responsibilities
- scalability of intelligence layers

---

## AVOT Classification System

Each AVOT is assigned:

- **ID** → unique identifier
- **Name** → functional designation
- **Domain** → primary responsibility layer
- **Phase** → where it operates in routing
- **Status** → active / emerging / future

## System Rules

1. No AVOT duplicates another’s function  
2. All AVOTs must map to a routing phase  
3. New AVOTs must be registered before activation  
4. Guardian approval required for new core AVOTs
